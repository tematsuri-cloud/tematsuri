将棋ゲームアプリ Shogi Game - Attack 50

将棋の駒たちがキャラクターとなって戦う、初心者でも楽しめる新しい戦略ゲーム。 ルールはシンプル。けれど一手ごとにドラマがある。 あなたの指す一手が、戦局を変える――。 さあ、「負けない将棋」で自分だけの戦い方を見つけよう！

⚔️ ゲームの内容

本作は、基本ルールは将棋と同じですが、 50手以内に勝てなかった場合は引き分けとなる 「負けない将棋ゲーム」です。 初心者でも安心してプレイでき、 攻める楽しさに集中できます。

A beginner-friendly shogi game with characters. Learn shogi rules while enjoying the game.

rule

Shogi Game : Attack 50 follows the basic rules of shogi. If the game does not end within 50 moves, it will be a draw. This is a "no-lose" shogi game, designed for beginners to enjoy aggressive play without pressure.
